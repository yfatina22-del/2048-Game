# 2048-Game
Tugas coding ka WB
2048 is a single player sliding-tile number puzzle game.
There is a 4×4 grid.
Each turn you can move tiles up, down, left, or right.
When two tiles with the same number collide, they merge into one tile (for example, 2+2=4, 4+4=8).
After every move, a new tile (2 or 4) appears.
The goal is to create the 2048 tile.
